# 🐾 JHYProject (작업 중 / Work In Progress)

동물 캐릭터들이 공중에 떠 있는 박스를 점프하며 콤보를 쌓는 모바일 캐주얼 게임입니다.  
A casual mobile game where animal characters leap between floating boxes and stack combos through precise timing.

---

## 🔧 기술 스택 (Tech Stack)

- **Unity**: 6.0.41f
- **Firebase**: Authentication, Firestore
- **UniTask**: 비동기 처리용 유틸리티
- **DOTween**: 트윈 기반 애니메이션 시스템

---

## 🚀 주요 기능 (Key Features)

- 🦘 정밀 타이밍 기반 점프 콤보 시스템
- 🎮 모바일 최적화 입력 처리
- 🔥 Firebase 기반 유저 데이터 및 점수 관리
